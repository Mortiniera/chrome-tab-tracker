# 🚀 Inactive Tab Tracker - Chrome Extension

**Automatically track and close inactive tabs to make browsing experience lightweight.**  

🟢 **Keep your Chrome Browser clean & fast by automatically tracking tabs based on inactivity time.**  
🔵 **Select a time threshold and close tabs that haven’t been used.**  
🔴 **Never worry about too many open tabs again!**

---

![Inactive Tab Tracker](<img src="images/demo.png">)

## 📌 Features
✅ **Track when each tab was last used**  
✅ **Select inactivity thresholds (e.g 30 min, 1 day, etc.)**  
✅ **Auto-refreshes when you open the extension**  
✅ **One-click tab closing**  
✅ **Lightweight & easy to use**
